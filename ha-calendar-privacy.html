Privacy policy

This policy covers the "Home Assistant" application that links one household's own Home Assistant installation to Google Calendar. It is for personal use and is not offered to the public.

Data accessed

With the account owner's consent, the application can read and change calendars and events of that Google account. The household uses only its family calendar.

How the data is used and stored

Events are used only to show the calendar in Home Assistant, to run home automations and to send reminders. Event data and the access tokens are stored on the household's own Home Assistant system.

Sharing

The data is not sold, not used for advertising and not given to other people. Reminders with event titles and times may be delivered to the household's own members through the Telegram messaging service.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions, or by deleting the integration in Home Assistant, which stops any further use of the data.

Google API data

The use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
